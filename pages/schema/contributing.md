## Contributing to the DIST schema

DIST is an open source project, and we welcome contributions from anyone who wishes to help shape the future of the schema.

The schema is developed in [this git repository](https://github.com/thegreenwebfoundation/DIST/tree/main/schema/dist), where you can see the canonical JSON schema file for each version, and keep track of our work in progress.

To get involved in the shaping of the vision and implementation of this section of DIST, take a look at [the issues we are working on](https://github.com/thegreenwebfoundation/DIST/issues) in github - we welcome feature requests, bug reports and pull requests from the wider DIST community.
